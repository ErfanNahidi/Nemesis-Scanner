# Nemesis Scanner نسخهٔ 4.0.0

[English](README.md) · [راهنمای کامل](MANUAL.md)

Nemesis Scanner یک رابط خط فرمان Python برای Nmap است. می‌تواند روی هدف‌های مجاز اسکن انجام دهد، سرویس‌های پیدا‌شده را با امضاهای محلی آسیب‌پذیری تطبیق دهد، در صورت انتخاب به NVD متصل شود، برخی سرویس‌ها را بررسی کند و گزارش بسازد.

> فقط روی سامانه‌ها و شبکه‌هایی استفاده کنید که مالک آن هستید یا مجوز صریح ارزیابی آن‌ها را دارید. اسکن ممکن است روی سرویس‌ها اثر بگذارد و بعضی حالت‌های Nmap به دسترسی مدیریتی نیاز دارند.

## امکانات نسخهٔ 4

- منوهای تعاملی فشرده با لوگوی ASCII و رنگ قرمز Nemesis.
- presetهای اسکن شبکه: Quick، Full، Turbo، Stealth، IPv6 و Custom.
- presetهای ارزیابی آسیب‌پذیری با منبع Offline یا Online NVD.
- بازبینی گزارش ذخیره‌شده با IP دستگاه در سطح‌های Quick، Medium و Deep.
- بازبینی Deep برای حداکثر ۶ سرویس گزارش به NVD درخواست تازه می‌فرستد؛ اسکن Nmap جدید اجرا نمی‌کند.
- گزارش‌های JSON، CSV و HTML و امکان ذخیرهٔ خودکار.
- امضاهای محلی در `core/static_vulns.json` و cache پایدار پاسخ‌های NVD در `core/nvd_cache.json`.

## پیش‌نیازها

- Python نسخهٔ 3.8 یا جدیدتر.
- Nmap نسخهٔ 7.80 یا جدیدتر و قابل دسترسی از `PATH`.
- وابستگی‌های Python فهرست‌شده در `requirements.txt`.
- اینترنت فقط برای lookup آنلاین NVD/Vulners و دریافت به‌روزرسانی پروژه لازم است.

برخی حالت‌های Nmap و تشخیص سیستم‌عامل به دسترسی root/Administrator نیاز دارند. پیش از اجرا، مجوز و محدودهٔ تست را با مالک سامانه هماهنگ کنید.

## نصب

ابتدا Nmap را نصب کنید.

```bash
# Debian / Ubuntu
sudo apt update
sudo apt install nmap

# macOS
brew install nmap
```

در Windows، Nmap را از [nmap.org](https://nmap.org/download.html) نصب و مسیر آن را به `PATH` اضافه کنید.

در ریشهٔ پروژه وابستگی‌های Python را نصب کنید:

```bash
python -m pip install -r requirements.txt
```

`Jinja2` اختیاری است و فقط برای گزارش HTML استفاده می‌شود. بدون آن، گزارش JSON و CSV همچنان در دسترس است.

## شروع سریع

بازکردن منوی تعاملی:

```bash
python cli.py
```

اجرای preset از خط فرمان:

```bash
python cli.py 192.0.2.10 -m quick
```

`192.0.2.10` فقط یک IP نمونه برای مستندات است؛ آن را فقط با هدف مجاز خود جایگزین کنید.

در منو دو مسیر جدا وجود دارد:

1. **اسکن جدید:** اجرای Nmap با preset انتخابی و امکان ذخیرهٔ نتیجه.
2. **بازبینی نتیجهٔ قبلی:** خواندن آخرین گزارش JSON یک IP و تحلیل آن بدون شروع اسکن شبکه.

## منوهای تعاملی

### Network Discovery & Port Scanning

- **Quick TCP:** فهرست رایج TCP و UDP؛ سریع‌ترین preset معمولی.
- **Full TCP:** پورت‌های TCP از ۱ تا ۶۵۵۳۵ به‌همراه فهرست UDP برنامه؛ ممکن است بسیار طولانی شود.
- **Turbo:** فهرست محدود پورت‌های مهم؛ سریع است اما ممکن است سرویس‌های پورت‌های دیگر را پیدا نکند.
- **Stealth SYN:** زمان‌بندی کندتر Nmap؛ فقط با مجوز کتبی استفاده شود.
- **IPv6:** فعال‌کردن حالت IPv6 در Nmap.
- **Custom:** دریافت آرگومان‌های اضافهٔ Nmap.

پس از انتخاب اسکن، برنامه می‌پرسد گزارش خودکار ذخیره شود یا خیر. در صورت تأیید، قالب JSON، CSV یا HTML را انتخاب کنید. فایل‌ها در `reports/` ذخیره می‌شوند.

### Vulnerability Assessment

ابتدا می‌توانید **نتیجهٔ قبلی را بازبینی کنید** یا **اسکن آسیب‌پذیری جدید** را شروع کنید.

بازبینی نتیجهٔ قبلی، IP دستگاه را می‌گیرد و آخرین گزارش همان IP را از `reports/` می‌خواند:

| سطح | منبع داده | فعالیت شبکه |
| --- | --- | --- |
| Quick | یافته‌های موجود در گزارش | ندارد |
| Medium | گزارش به‌همراه امضاهای محلی `core/static_vulns.json` | ندارد |
| Deep | داده‌های Medium به‌همراه استعلام تازهٔ NVD برای حداکثر ۶ سرویس | فقط درخواست NVD؛ اسکن Nmap جدید اجرا نمی‌شود |

Deep ممکن است طول بکشد و محدودیت نرخ NVD روی آن اثر بگذارد. کلید اختیاری NVD می‌تواند نرخ مجاز API را افزایش دهد. اگر درخواست تازه شکست بخورد و دادهٔ متناظر در cache وجود داشته باشد، نتیجه به‌عنوان fallback مشخص می‌شود. تعداد یافته‌ها بر اساس شدت نمایش داده می‌شود و می‌توان گزارش بازبینی را جداگانه در `reports/` ذخیره کرد.

اسکن آسیب‌پذیری جدید presetهای Quick، Medium، Deep، Web checks، Directory services و Custom دارد. منبع CVE را می‌توان Offline یا Online NVD انتخاب کرد. حالت Online به اینترنت نیاز دارد و جست‌وجوی Vulners به کلید API آن نیازمند است.

### Full Attack Surface Analysis

منوی Full شامل presetهای Standard، Aggressive، Stealth و Turbo است. هرکدام اسکن جدیدی اجرا می‌کنند. برای اینکه بعداً نتیجه را با IP مرور کنید، پس از انتخاب preset ذخیرهٔ گزارش خودکار را تأیید کنید.

## حالت‌های اسکن

| حالت | پورت‌های TCP | پورت‌های UDP | توضیح |
| --- | --- | --- | --- |
| `quick` | فهرست انتخابی رایج، حدود ۳۸ پورت | فهرست رایج انتخابی | سریع‌تر؛ بررسی نسخه تابع گزینه‌های آسیب‌پذیری است. |
| `common` | ۱ تا ۱۰۰۰ | فهرست رایج برنامه | تشخیص نسخه فعال است. |
| `full` | ۱ تا ۶۵۵۳۵ | فهرست رایج برنامه | پوشش بیشتر و زمان بسیار طولانی‌تر. |
| `turbo` | فهرست محدود پورت‌های مهم | فهرست محدود پورت‌های مهم | سریع اما با پوشش محدود. |
| `custom` | طبق `--nmap-args` | طبق `--nmap-args` | آرگومان‌های سفارشی به Nmap داده می‌شوند. |

مدت واقعی به دسترسی‌پذیری هدف، فیلترینگ، شبکه، سطح دسترسی و رفتار Nmap بستگی دارد؛ هیچ preset زمان پایان ثابتی را تضمین نمی‌کند.

## گزینه‌های خط فرمان

```text
usage: cli.py [targets ...] [options]

آرگومان‌های اصلی:
  targets                    IP، نام میزبان یا CIDR
  -m, --mode MODE            quick، common، full، custom یا turbo (پیش‌فرض quick)
  -t, --threads N            تعداد وظایف هم‌زمان هدف‌ها (پیش‌فرض 10)
  -o, --output NAME          پایهٔ نام فایل خروجی، بدون پسوند
  --format FORMAT            json، csv، html یا all (پیش‌فرض json)
  --vuln-check               فعال‌کردن تطبیق آسیب‌پذیری و اسکریپت‌های Nmap
  --vuln-source SOURCE       offline یا online (پیش‌فرض offline)
  --nvd-key KEY              کلید NVD
  --vulners-key KEY          کلید Vulners برای افزودن اطلاعات exploit
  --nmap-args ARGS           آرگومان‌های اضافهٔ Nmap
  --stealth                  زمان‌بندی کندتر stealth
  --aggressive               زمان‌بندی aggressive
  --turbo                    preset زمان‌بندی و پورت Turbo
  --fragment                 درخواست fragment کردن بسته‌ها از Nmap
  --source-port PORT         تعیین source port
  --spoof-mac MAC            گزینهٔ MAC address برای Nmap
  --decoys LIST              مقادیر decoy جداشده با کاما
  --ttl VALUE                تعیین TTL
  --auth-check               گزینهٔ رزروشده برای بررسی پایهٔ احراز هویت
  --auto-save                ذخیرهٔ خودکار گزارش زمان‌دار در reports/
  --deep-inspect             فعال‌کردن بررسی عمیق (پیش‌فرض فعال)
  --no-deep-inspect          غیرفعال‌کردن بررسی عمیق
  --skip-ping                به Nmap اجازهٔ host discovery می‌دهد؛ پیش‌فرض -Pn است
  --ipv6                     فعال‌کردن IPv6
  --email ADDRESS            گزینهٔ اعلان که فعلاً در runner اعمال نمی‌شود
  --slack URL                گزینهٔ اعلان که فعلاً در runner اعمال نمی‌شود
  --config FILE              پذیرفته می‌شود، اما بارگذاری config پیاده‌سازی نشده
  --interactive              بازکردن منوی تعاملی
```

مثال‌ها:

```bash
# اسکن Quick روی هدف مجاز
python cli.py 192.0.2.10 -m quick

# فعال‌کردن بررسی آسیب‌پذیری و ذخیرهٔ خودکار JSON
python cli.py 192.0.2.10 -m common --vuln-check --vuln-source offline --auto-save

# ساخت هر سه قالب با مسیر خروجی مشخص
python cli.py 192.0.2.10 -m common --vuln-check -o reports/example --format all

# بازکردن منو
python cli.py --interactive
```

`--config`، `--email` و `--slack` در parser پذیرفته می‌شوند اما runner فعلی آن‌ها را اعمال نمی‌کند. `--format all` با `-o` هر سه قالب را می‌سازد؛ ذخیرهٔ خودکار یک قالب انتخابی را می‌نویسد.

## منبع CVE، دادهٔ محلی و cache

- `core/static_vulns.json` فهرست امضاهای محلی و دستی است که بررسی Offline/Medium از آن استفاده می‌کند. نمونهٔ کلید: `"smb,1.0"` و مقدار آن فهرستی از توضیحات است.
- lookup آنلاین NVD درخواست تازه می‌فرستد و پاسخ موفق را در `core/nvd_cache.json` ذخیره می‌کند.
- lookup آفلاین NVD می‌تواند پاسخ cacheشدهٔ قبلی را برای عبارت جست‌وجوی متناظر بخواند. فایل امضاهای دستی و cache NVD دو منبع جدا هستند.
- نتایج NVD جست‌وجوی کلیدواژه‌ای بر اساس نام سرویس/محصول/نسخه هستند و به‌تنهایی اثبات نمی‌کنند CVE روی دستگاه اعمال می‌شود. نسخه و توصیهٔ فروشنده را بررسی کنید.
- ابزار به‌روزرسان خودکار برای `static_vulns.json` ندارد.

درخواست کلید NVD: [NVD API Key Request](https://nvd.nist.gov/developers/request-an-api-key). کلید Vulners اختیاری است و فقط برای enrichment سرویس Vulners لازم است.

## گزارش‌ها و فایل‌های داده

- گزارش اسکن زمان‌دار: `reports/<target>_<YYYYMMDD_HHMMSS>.<ext>`.
- گزارش بازبینی: `reports/<target>_review.json`.
- امضاهای محلی: `core/static_vulns.json`.
- cache پاسخ NVD: `core/nvd_cache.json`.

گزارش‌ها ممکن است IP، سرویس‌ها، نسخه‌ها، جزئیات آسیب‌پذیری و زمان اسکن را داشته باشند؛ آن‌ها را مانند دادهٔ حساس ارزیابی امنیتی نگهداری کنید.

## رفع اشکال

- **Nmap پیدا نمی‌شود:** Nmap را نصب کنید و مطمئن شوید در `PATH` قرار دارد.
- **خطای دسترسی یا نتیجهٔ ناقص:** برخی حالت‌های Nmap به دسترسی مدیریتی نیاز دارند؛ فقط در محیط مجاز اجرا کنید.
- **برای IP گزارشی نیست:** ابتدا اسکن مجاز انجام دهید و ذخیرهٔ گزارش را فعال کنید؛ بازبینی آخرین گزارش همان IP را می‌خواند.
- **بازبینی Online از cache استفاده کرد:** اگر NVD در دسترس نباشد، رابط اعلام می‌کند نتیجه fallback از cache بوده است.
- **محدودیت نرخ NVD:** تعداد lookupهای آنلاین را کم کنید یا از کلید API استفاده کنید.
- **گزارش HTML ساخته نمی‌شود:** `Jinja2` را با `python -m pip install jinja2` نصب کنید.
- **ماژول Python پیدا نمی‌شود:** `python -m pip install -r requirements.txt` را در همان محیطی اجرا کنید که برنامه را اجرا می‌کند.

## مجوز استفاده

این نرم‌افزار را فقط روی سامانه‌هایی استفاده کنید که مالک آن هستید یا مجوز صریح ارزیابی آن‌ها را دارید. محدوده، زمان اجرا، نرخ و الزامات اطلاع‌رسانی را با مالک هماهنگ کنید. نویسندگان پروژه مسئول استفادهٔ غیرمجاز یا خسارت ناشی از آن نیستند.
