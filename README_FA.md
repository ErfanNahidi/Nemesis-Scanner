# Nemesis Scanner – Monster Edition v3.0.0

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-Custom-red.svg)](LICENSE)
[![Version](https://img.shields.io/badge/Version-3.0.0-green.svg)]()

**نِمِسیس اِسکَنِر** یک ابزار پیشرفتهٔ شناسایی شبکه و آسیب‌پذیری، مبتنی بر **Nmap** و مستقل از سیستم‌عامل است.  
مناسب برای تست‌نفوذ، تیم‌های قرمز و ممیزان امنیتی که به اسکن‌های سریع، عمیق و قابل حمل روی **هر پلتفرمی** نیاز دارند.

## 🆕 ویژگی‌های جدید نسخه 3.0.0

- 🔍 **بازرسی عمیق فعال** – بررسی FTP ناشناس، هدرهای امنیتی HTTP، ضعف‌های TLS/SSL.
- 📊 **شدت آسیب‌پذیری و امتیاز CVSS** – طبقه‌بندی Critical/High/Medium/Low به‌همراه امتیاز CVSS از NVD.
- ⚡ **افزایش سرعت** – فعال بودن `-Pn` به‌صورت پیش‌فرض، بهینه‌سازی زمان‌بندی و هم‌روندی بیشتر.
- 💾 **کش کردن درخواست‌ها** – ذخیرهٔ نتایج NVD و Vulners برای جلوگیری از محدودیت نرخ.
- 📁 **پایگاه دادهٔ آسیب‌پذیری خارجی** – امکان بارگذاری `static_vulns.json` سفارشی.
- 📋 **منوهای دسته‌بندی‌شدهٔ جدید** – Network Discovery, Vulnerability Assessment, Full Attack Surface Analysis.
- 🌐 **پشتیبانی از IPv6** – اسکن اهداف IPv6 با پرچم `--ipv6`.
- 🛡️ **پرچم‌های جدید** – `--deep-inspect`، `--no-deep-inspect`، `--skip-ping`.

## ✨ ویژگی‌های اصلی

- **حالت‌های متنوع اسکن** – سریع (Quick)، معمولی (Common)، کامل (Full)، سفارشی (Custom)، **توربو (Turbo)**.
- **تشخیص سرویس، نسخه و سیستم‌عامل** با اسکریپت‌های NSE.
- **تشخیص آسیب‌پذیری چندلایه** – پایگاه دادهٔ ایستا + جست‌وجوی زندهٔ CVE از NVD و Vulners.
- **شدت‌بندی و امتیازدهی CVSS** – نمایش سطح بحرانی‌بودن هر آسیب‌پذیری.
- **بازرسی عمیق فعال** – بررسی بدون تخریب سرویس‌ها (FTP، HTTP، TLS).
- **لینک به اکسپلویت‌ها** – اتصال خودکار به Exploit‑DB و Vulners.
- **نقشهٔ سطح حمله** – نگاشت پورت‌های باز به ماژول‌های حملهٔ شناخته‌شده.
- **گزارش‌گیری چندفرمته** – کنسول رنگی، JSON، CSV، HTML.
- **ذخیرهٔ خودکار گزارش‌ها** با نام IP + زمان در پوشهٔ `reports/`.
- **اعلان‌ها** – ایمیل و وب‌هوک Slack.
- **تکنیک‌های گریز** – حالت مخفی‌سازی، آدرس‌های فریب، قطعه‌قطعه‌سازی بسته‌ها، جعل MAC و …
- **منوی تعاملی پیشرفته** – بدون نیاز به حفظ دستورات.

## 📦 نصب

### ۱. نصب Nmap
```bash
# دبیان/اوبونتو/کالی
sudo apt update && sudo apt install nmap -y

# مک (Homebrew)
brew install nmap
```

### ۲. نصب وابستگی‌های پایتون
```bash
pip install -r requirements.txt
```

*requirements.txt*:
```
python-nmap
requests
colorama
pyyaml
jinja2
```

### ۳. دریافت پروژه
```bash
git clone https://github.com/ErfanNahidi/Nemesis-Scanner.git
cd Nemesis-Scanner
```

### ۴. (اختیاری) دریافت کلیدهای API
- **NVD API key:** [https://nvd.nist.gov/developers/request-an-api-key](https://nvd.nist.gov/developers/request-an-api-key)
- **Vulners API key:** [https://vulners.com](https://vulners.com) (ثبت‌نام رایگان)

## 🚀 شروع سریع

**خط فرمان:**
```bash
sudo python3 cli.py 192.168.1.10 -m quick
```

**منوی تعاملی:**
```bash
sudo python3 cli.py
```
سپس از منوی اصلی، گزینهٔ دلخواه (Network، Vulnerability، Full Analysis) را انتخاب کنید.

## 📖 حالت‌های اسکن

| حالت       | پورت‌های TCP               | پورت‌های UDP       | تشخیص نسخه/OS | اسکریپت/بررسی CVE | سرعت    |
|------------|----------------------------|--------------------|----------------|--------------------|---------|
| `quick`    | ~۳۸ پورت بحرانی            | ~۱۰ پورت رایج UDP  | اختیاری        | بله (در صورت فعال‌بودن) | سریع    |
| `common`   | ۱۰۰۰ پورت برتر TCP         | ۲۰ پورت رایج UDP   | بله            | بله                | متوسط   |
| `full`     | تمام ۶۵۵۳۵ پورت TCP        | ۲۰ پورت رایج UDP   | بله            | بله                | بسیار کند |
| `custom`   | توسط `--nmap-args` تعیین می‌شود | طبق آرگومان‌ها    | طبق آرگومان‌ها | بله                | متغیر   |
| `turbo`    | ۱۵ پورت بحرانی TCP + UDP   | ۶ پورت بحرانی UDP  | اختیاری        | بله                | فوق‌سریع |

**حالت توربو** با بهینه‌سازی‌های زیر:
- زمان‌بندی T5، نرخ ۱۰,۰۰۰ بسته در ثانیه
- بدون تلاش مجدد، بدون پینگ، بدون DNS
- حداکثر هم‌روندی ۲۵۶
- مهلت ۱۰۰ میلی‌ثانیه‌ای RTT، مهلت ۳۰ ثانیه‌ای میزبان
- تشخیص نسخهٔ سبک در صورت فعال بودن بررسی آسیب‌پذیری
